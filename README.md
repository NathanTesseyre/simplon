# Formation Admin Système DevOps Junior — Vault Obsidian

Fiches de cours pour la formation **Admin Système DevOps Junior** (Simplon).

> **C'est quoi un "vault" ?** C'est simplement un dossier de fichiers Markdown organisés. Tu peux les lire avec n'importe quel éditeur, mais [Obsidian](https://obsidian.md/) (gratuit) offre une navigation par liens et un graphe visuel qui rend la consultation bien plus agréable.

## Démarrage rapide

1. **Télécharger** — clone ce dépôt ou télécharge-le en ZIP (bouton vert "Code" sur GitHub)
2. **Ouvrir dans Obsidian** — lance Obsidian > "Ouvrir un dossier comme vault" > sélectionne ce dossier
3. **Commencer** — ouvre [`00-MOC/MOC-Principal.md`](00-MOC/MOC-Principal.md), c'est la page d'accueil du vault

> Sans Obsidian, ouvre simplement les fichiers `.md` dans VS Code, Notepad++ ou n'importe quel éditeur texte.

## Parcours conseillé

Suis cet ordre si tu débutes — chaque étape s'appuie sur la précédente :

```
1. Fondamentaux   →   2. Architecture   →   3. Sécurité   →   4. Environnements   →   5. DevOps
   (bases OS/réseau)     (comment ça s'assemble)  (protéger)        (Linux, Docker…)        (CI/CD, Infra as Code)
```
